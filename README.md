# Pinyi Wang's academic homepage

A static website for https://pinyi-wang.github.io/.

## Publish on GitHub Pages

1. Sign in to GitHub as `pinyi-wang`.
2. Create a public repository named `pinyi-wang.github.io`.
3. Upload `index.html`, `style.css`, and `.nojekyll` to the repository root (not inside an extra folder).
4. Open Settings → Pages. Under Build and deployment, choose Deploy from a branch, then `main` and `/ (root)`, and save.
5. Wait for the Pages deployment to finish, then visit https://pinyi-wang.github.io/.

Edit `index.html` to update the content and `style.css` to adjust the appearance. No build step or dependencies are needed.
